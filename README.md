\# Credit Card Fraud Detection on AWS SageMaker



End-to-end ML pipeline that detects fraudulent credit card transactions,

from data prep through deployment and monitoring.



\## Problem

Fraud is rare (\~0.17% of transactions), so accuracy is misleading. This

project focuses on handling class imbalance and optimizing for recall

on the fraud class.



\## Dataset

\[Credit Card Fraud Detection (Kaggle / ULB)](https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud)



\## Stack

AWS S3, SageMaker (Studio, Training Jobs, Endpoints, Model Monitor), XGBoost, Python
